# 天统AI京东多店经营工作台 R298

这是 R298 Windows x64 多店全自动页面识别与云端同步客户端。客户端固定连接：

`https://internal.tiantongai.com`

## 安全边界

- 店铺由云端授权，客户端不能自行新增。
- 配对码为一次性 8 位数字，有效期 10 分钟。
- 每家店铺使用独立的持久化浏览器分区。
- 京东账号、密码、短信、二维码和验证码仅由员工在京东页面手工输入。
- 京东官方页面按标准 Chromium 浏览器网络行为运行，不再按 POST/RPC 名称误拦登录和页面读取。
- 顶层页面只允许精确匹配的京东官方域名，外站跳转与下载仍被阻止。
- 经营首页、店铺管理、数据同步、异常预警和只读浏览模式均为可操作按钮。
- 自动识别京麦首页、京东商智、订单、商品、库存、售后和推广页面类型。
- 每10秒只读识别一次白名单经营指标，不保留原始页面文本。
- 不读取密码、Cookie、表单、买家姓名、手机号或收货地址。
- 配对成功后每5分钟自动轮询全部授权店铺，只把白名单指标通过设备私钥签名上传到云端。
- 验证码、风控或登录失效只暂停对应店铺，其他店铺继续同步；云端失败按1、3、10分钟重试。
- Windows安装版随用户登录自动启动，“立即同步全部”保留为人工备用按钮。
- 云端按租户、公司和店铺三层校验并隔离保存，重复提交不会重复写入。
- 老板驾驶舱读取各店铺最近一次成功同步的数据；没有真实值时继续显示暂无数据。

## 本地检查

```powershell
npm ci --no-audit --no-fund
npm run check
```

## Windows 构建

```powershell
npm run dist:win
```

输出到 `dist/`：

- `TiantongAI-JD-Workbench-2.98.0-r298-x64.exe`
- `TiantongAI-JD-Workbench-2.98.0-r298-x64.zip`

内部验收版本未进行 Authenticode 代码签名，Windows SmartScreen 可能提示“未知发布者”。正式分发前必须配置组织代码签名证书。
